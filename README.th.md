# PUI89 Sentinel — หุ่นยนต์สำรวจและตรวจสอบแบบสี่ขา

[English README](README.md) · [พอร์ตโฟลิโอ PUI89](https://pui89.github.io/)

## ภาพรวมผลิตภัณฑ์

PUI89 Sentinel เป็นแนวคิดแพลตฟอร์มหุ่นยนต์สี่ขาสำหรับการสำรวจและตรวจสอบพื้นที่ โดยมีผู้ควบคุมเป็นผู้กำหนดภารกิจและตัดสินใจ ระบบมุ่งช่วยสังเกต บันทึก และจัดลำดับประเด็นที่ควรตรวจสอบในพื้นที่อุตสาหกรรม โครงสร้างพื้นฐาน โลจิสติกส์ และพื้นที่กลางแจ้งที่เหมาะสม

## ความสามารถและแนวทางพัฒนา

- วิเคราะห์ภาพ RGB เพื่อรับรู้บุคคล วัตถุ เครื่องจักร ป้าย และสภาพพื้นผิว
- ศึกษาการใช้ Depth, LiDAR, Thermal, เสียง และเซนเซอร์สิ่งแวดล้อมตามภารกิจ
- ทำแผนที่ ระบุตำแหน่ง และตรวจจับสิ่งกีดขวางเมื่อมีอุปกรณ์และการปรับเทียบรองรับ
- รวมข้อมูลหลายเซนเซอร์พร้อมเวลา แหล่งที่มา สุขภาพเซนเซอร์ และค่าความไม่แน่นอน
- เปรียบเทียบสภาพตามเวลา จัดลำดับความผิดปกติ และจัดทำรายงานหลักฐาน
- ศึกษาการเดินสี่ขา การทรงตัว การสัมผัสพื้น การลื่น และ safe hold
- ใช้ Simulation/Digital Twin ก่อนการทดสอบภาคสนาม

## สถานะและขอบเขตหลักฐาน

Sentinel ยังเป็นแนวคิดผลิตภัณฑ์และแนวทางวิศวกรรม ยังไม่มีการยืนยันว่าชุดเซนเซอร์ ระบบเดิน การทำแผนที่ หรือการทำงานในพื้นที่อันตรายถูกรวมเป็นระบบและผ่านการทดสอบแล้ว

คำว่า “All-Terrain” เป็นทิศทางการออกแบบ ไม่ใช่การรับประกันว่าสามารถผ่านทุกสภาพพื้นผิวได้ RGB, Depth หรือ LiDAR ไม่สามารถรับรองความปลอดภัยของบรรยากาศหรือแทนเครื่องมือตรวจวัดก๊าซที่เหมาะสมได้

## ขั้นตอนหลักฐานถัดไป

1. กำหนดภารกิจตรวจสอบแรกและพื้นที่ใช้งานที่ชัดเจน
2. สำรวจสถานที่และจัดทำข้อกำหนดด้านอันตราย/ความปลอดภัย
3. เลือกเซนเซอร์เฉพาะภารกิจและตรวจสอบแหล่งที่มา
4. ทดสอบ perception และการเคลื่อนที่แยกส่วนในสภาพควบคุม
5. ตรวจสอบ safe stop, fault reporting, recovery และการควบคุมโดยมนุษย์

**หลักความปลอดภัย:** ผู้ควบคุมยังคงมีอำนาจเหนือภารกิจ การแจ้งเตือนและข้อเสนอจาก AI ต้องตรวจสอบได้ และไม่ถือเป็นการรับรองความปลอดภัยของพื้นที่
