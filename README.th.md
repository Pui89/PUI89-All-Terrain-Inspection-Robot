# เก็บถาวร — PUI89 Sentinel

**สถานะโครงการ: ยุติเมื่อวันที่ 24 พฤศจิกายน 2026**

PUI89 Sentinel ไม่ใช่ผลิตภัณฑ์ที่ดำเนินการอยู่ของ PUI89 อีกต่อไป ไม่มีการอนุมัติให้พัฒนาผลิตภัณฑ์ จัดหาชุดข้อมูล ประเมินโมเดล ดำเนินงานวิศวกรรม จัดซื้อ ผลิต นำไปใช้งาน หรือให้การสนับสนุนภายใต้โครงการนี้ต่อไป

Repository นี้เก็บไว้เป็นบันทึกทางประวัติศาสตร์เท่านั้น เนื้อหาภายในไม่ใช่ข้อกำหนดผลิตภัณฑ์ที่ใช้งานอยู่ แบบที่ได้รับอนุมัติ แผนงานปัจจุบัน หรือหลักฐานว่ามีผลิตภัณฑ์ PUI89 ที่รองรับอยู่ ห้ามใช้ Repository นี้เป็น Dependency ที่กำลังพัฒนา หรือเริ่มงานใหม่จากเอกสารเก่า

พอร์ตโฟลิโอ PUI89 ที่ยังดำเนินการอยู่แสดงไว้ใน [เว็บไซต์ PUI89](https://pui89.github.io/) และ [เอกสาร Portfolio Source of Truth](https://pui89.github.io/docs/PUI89_PORTFOLIO_SOURCE_OF_TRUTH_V1.3.md) ส่วน Shared AI Core ยังคงเป็นโครงสร้างพื้นฐานร่วมสำหรับผลิตภัณฑ์ที่เหลือ และไม่ได้รับผลกระทบจากการยุติโครงการนี้

เก็บประวัติ Git ไว้เพื่อการตรวจสอบย้อนหลัง ประกาศเก็บถาวรนี้ไม่ได้หมายความว่า Repository หรือประวัติถูกลบแล้ว
